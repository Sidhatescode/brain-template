End of session. Distill what happened and write it back so nothing is lost to chat history.

1. Review the session's conversation for: decisions made, things learned, problems hit, and
   open questions or follow-ups.
2. For anything substantial enough to be reusable later, file it into `wiki/` following the
   page-type and linking conventions in `CLAUDE.md` (don't create a page for something
   trivial or already covered by an existing page — update the existing page instead).
3. Update `wiki/index.md` for any new or changed pages.
4. Append one entry to `wiki/log.md`:
   `## [YYYY-MM-DD] session | <one-line summary>`
   followed by a few bullets: decisions, learnings, open questions/next steps.
5. Confirm with the human what was written before finishing — show a short summary, don't
   just silently commit changes.
